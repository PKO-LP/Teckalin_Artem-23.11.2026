## Версия и среда

Проверяемая версия: `0.3.1` (`После_исправления/app.py`).
Среда проверки: ОС Windows / Linux, Python 3 с модулем Tkinter, запуск из VS Code Terminal (`python После_исправления/app.py`).

## Регрессионная проверка

Выполнена проверка всех функций версии 0.2.0 / 0.3.0:

- пошаговое увеличение счётчика на 1 до границы лимита;
- циклический переход статусов `Новая` -> `В работе` -> `Готово` -> `Новая`;
- увеличение счётчика «Закрыто заявок» на 1 при каждом переходе в статус «Готово»;
- корректное отображение даты в формате `ДД.ММ.ГГГГ ЧЧ:ММ`;
- закрытие окна крестиком без ошибок в терминале.
  Регрессионных дефектов не выявлено.

## Критерии приёмки

Выпуск `0.3.1` считается принятым, если пройдены все тесты `TC-01`–`TC-04` и регрессионные проверки без критических и высоких дефектов, в окне указана версия `0.3.1`, а комплект содержит рабочий `app.py`, `logo.png` и документацию.
